
## **Rôle du DHCP**

Le service DHCP de pfSense est **activé sur l’interface LAN**. Il permet d’attribuer automatiquement une adresse IP aux machines du réseau interne `gns` (Windows et Ubuntu).

Le DHCP fournit automatiquement :
- une **adresse IP**
- un **masque**
- une **passerelle** (192.168.1.1)
- un **DNS** (192.168.1.1)
- une **durée de bail** (lease time)

Sans DHCP, les machines du LAN devraient être configurées manuellement.

## **Plage d’adresses distribuées**

Le DHCP distribue des adresses dans la plage :
192.168.1.100 → 192.168.1.200

Cette plage se situe dans le réseau LAN :
192.168.1.0/24

Adresse de pfSense (LAN): 
192.168.1.1

### Adresses réservées pour les VM
- Windows : 192.168.10.100–200
- Ubuntu : 192.168.10.100–200

## **Paramètres DHCP importants**

### **Passerelle distribuée**

```
192.168.1.1
```
=> pfSense devient la passerelle par défaut.

### **DNS distribué**

```
192.168.1.1
```

=>  pfSense assure la résolution DNS (ou relaie vers Internet).

### **Durée du bail**
Par défaut : 1 jour 
=>  Les machines renouvellent automatiquement leur IP.

##  **Tests DHCP**

###  Windows
```
ipconfig
ipconfig /renew
```

On dois avoir :
- IPv4 : 192.168.1.1
- Passerelle : 192.168.1.1
- DNS : 192.168.1.1
###  Ubuntu
```
ip a
sudo dhclient -r
sudo dhclient
```

On dois avoir :
- inet 192.168.1.1/24
- gateway via 192.168.1.1
