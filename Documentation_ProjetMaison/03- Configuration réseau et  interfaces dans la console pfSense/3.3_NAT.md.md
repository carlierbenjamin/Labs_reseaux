(Network Address Translation)

## Rôle 
Le NAT permet aux machines du réseau interne `gns` (Windows et Ubuntu) d’accéder à Internet via pfSense. 
Il traduit les adresses privées du LAN (ex : 192.168.1.1) en une adresse WAN (ex : 192.168.122.61). 
Ensuite, VirtualBox NAT traduit cette adresse WAN en une adresse publique réelle.
Le NAT **cache** les adresses privées derrière une adresse WAN. 
Sans NAT, le réseau LAN serait isolé et ne pourrait pas accéder à Internet.

# 1. Architecture NAT du laboratoire

## WAN (NAT VirtualBox)
- Connecté à l’adaptateur **NAT VirtualBox**
- Reçoit automatiquement une IP (ex : `192.168.122.x`)
- Fournit l’accès Internet à pfSense
- C’est le **premier NAT** (VirtualBox → Internet)
## LAN (réseau interne gns)
- Réseau : **192.168.1.0/24**
- Passerelle : **192.168.1.1**
- DHCP : **192.168.1.100 -> 200**
- C’est le **réseau privé** où se trouvent la VM Windows Server et la VM Ubuntu client
Les machines du LAN utilisent pfSense comme passerelle pour sortir vers Internet.

---

# 2. Mode NAT utilisé par pfSense

## NAT sortant (Outbound NAT)
pfSense utilise par défaut le mode : **Automatic Outbound NAT**

Ce mode :
- crée automatiquement les règles NAT nécessaires
- permet aux machines du LAN d’accéder à Internet
- ne nécessite aucune configuration manuelle
- utilisé généralement pour les environnements pédagogiques (GNS3)

=> **Aucune règle NAT à créer manuellement.**

# 3. Fonctionnement du NAT 

### Étape 1 :  
Windows Server / Ubuntu client envoient du trafic vers Internet via la passerelle **192.168.1.1**

### Étape 2 :  
pfSense traduit l’IP source privée (ex : 192.168.1.1) en IP WAN (ex : 192.168.122.61)

### Étape 3 :  
VirtualBox NAT traduit ensuite l’IP WAN en une IP publique réelle

### Étape 4 :  
Le trafic revient à pfSense, qui renvoie la réponse au client LAN

Ce double NAT est normal dans un environnement VirtualBox + GNS3.

# 4. Vérifications NAT dans pfSense

## Vérifier l’IP WAN
Menu : **Status → Interfaces**

L’interface WAN doit afficher une IP du NAT VirtualBox (ex : 10.0.2.x).

# Tester le NAT avec une machine LAN

## Étape A — Connecter une machine LAN

Dans GNS3 desktop :
- Ajoute un **switch** (Ethernet Switch)
- Connecte **pfSense (em1**) au switch (ethernet0)
- Connecte **Windows** ou **Ubuntu** au switch
## Étape B — Vérifier l’IP LAN

La machine doit recevoir :
- IP : **192.168.1.x**
- Passerelle : **192.168.1.1**
- DNS : **192.168.1.1** ou **8.8.8.8**
## Étape C — Tester Internet depuis la machine LAN
ping 192.168.1.1
ping 8.8.8.8
ping google.com
