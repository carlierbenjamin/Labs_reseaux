## Rôle : réseau local connectant les périphériques (VM ubuntu et Windows)
 Les machines du LAN utilisent pfSense comme **passerelle** pour sortir vers Internet. 
 pfSense fournit :
  - une adresse IP (DHCP)
  - un DNS local (192.168.1.1)
  - un accès Internet via l’interface WAN

# Configuration
Menu pfSense → Option **2**
*Configure IPv4 via DHCP?* -> no
*Configure IPv4 statically* -> yes
- IPv4 statique : **192.168.1.1** (IP reseau : 192.168.1.0 /24)
- Masque : **/24**
- Pas de gateway
- Pas d’IPv6
- enable DHCP server : yes
	  - Start : **192.168.1.100****
	  - End : **192.168.1.200**
- Revert to HTTP as webconfigurator protocol? -> no
