
## 1. Rôle de la GNS3 VM

La GNS3 VM est une VM serveur emulant et simulant des équipements réseau (routeur/switchs...). Elle est importée dans VirtualBox via un fichier .ova et démarrée automatiquement par GNS3 Desktop.

## 8. Problèmes fréquents + Solutions

### 8.1 Hyper-V activé (VirtualBox bloqué) 
Symptôme : VM ne démarre pas. 
Solution : bcdedit /set hypervisorlaunchtype off Ou désactiver Hyper-V dans les fonctionnalités Windows.

### 8.2 eth1 DOWN dans la VM 
Solutions :
1. Reconnecter les câbles VirtualBox
2. Redémarrer la VM depuis VirtualBox
3. Type de carte → Intel PRO/1000 MT Desktop
4. Si adaptateur Host-Only corrompu :
VBoxManage hostonlyif remove "VirtualBox Host-Only Ethernet Adapter"
VBoxManage hostonlyif create
VBoxManage hostonlyif ipconfig "VirtualBox Host-Only Ethernet Adapter" --ip 192.168.56.1 --netmask 255.255.255.0
VBoxManage dhcpserver add --ifname "VirtualBox Host-Only Ethernet Adapter" --ip 192.168.56.100 --netmask 255.255.255.0 --lowerip 192.168.56.101 --upperip 192.168.56.254 --enable


### 8.3 Port 3080 absent 
Créer : sudo mkdir -p /etc/gns3 sudo nano /etc/gns3/gns3_server.conf
Contenu : 
[Server] 
host = 0.0.0.0 
port = 3080

Redémarrer : sudo systemctl restart gns3
Vérifier : ss -tlnp | grep 3080

### 8.4 Serveur GNS3 absent 
ls /usr/bin | grep gns3 
Si vide → installer :
sudo apt update sudo apt install -y python3 python3-pip python3-setuptools python3-dev libssl-dev libffi-dev libpcap-dev qemu-kvm qemu-utils ubridge dynamips vpcs

### 8.5 Test du serveur GNS3 
curl http://localhost:3080/v2/version 
Doit retourner un JSON.vvv
