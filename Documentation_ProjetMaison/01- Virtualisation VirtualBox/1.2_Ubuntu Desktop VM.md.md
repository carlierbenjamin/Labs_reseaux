# # 1. Télécharger l’image ISO Ubuntu Desktop

## Ubuntu Desktop **26.04 LTS** 

### Étapes :

1. Aller sur le site officiel Ubuntu : **[https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop?utm_source=copilot.com "ubuntu.com")**
2. Choisir : **Ubuntu 26.04 LTS**
3. Télécharger la version : **Ubuntu 26.04 LTS Desktop (64-bit / amd64)**
4. Fichier obtenu : **ubuntu-26.04-desktop-amd64.iso** (≈ 4 à 5 Go)
👉 **Ne jamais prendre ARM** (incompatible VirtualBox).

# # 2. Créer la VM Ubuntu Desktop dans VirtualBox

### Étape A — Nouvelle VM
- Nom : **UbuntuDesktop26**
- Type : **Linux**
- Version : **Ubuntu (64-bit)**
### Étape B — RAM / CPU
- RAM : **2048 MB (2 Go)** **
- CPU : **2 vCPU**
### Étape C — Disque
- Crée un disque virtuel : **32 Go**
- Format : **VDI**
- Mode : **Dynamically allocated**
### Étape D — Carte réseau
#### Adaptateur 1 :
- **Réseau interne / Internal Network**
- Nom : **LAN** (le même réseau interne que pfSense LAN)
- Adaptater Type : **Intel PRO/1000 MT Desktop**
- Promiscuous Mode : **Refuser**
#### Adaptateur 2 : désactivé

### Étape E — Monter l’ISO
Dans **Storage / Stockage** :
- Sélectionner le lecteur optique
- Choisir : **ubuntu-26.04-desktop-amd64.iso**
- Ajouter : **UbuntuDesktop26.vdi**
    
# # 3. Installer Ubuntu Desktop 26.04 LTS
Démarrer la VM → installation classique 
1. Choisir **Try or Install Ubuntu**
2. Choisir **Install Ubuntu**
3. Installation normale
4. Activer mises à jour
5. Créer un utilisateur (ubuntu26)
6. Mot de passe (AdminUbuntu26)
→ Arriver sur le bureau Ubuntu Desktop.

# # 4. Ajouter la VM dans GNS3

### Étape A — GNS3 → Preferences
- Edit → Preferences
- VirtualBox → VirtualBox VMs → Local computer
- Clique sur **New**
- Sélectionne **UbuntuDesktop26**

### Étape B — Ajouter dans ton projet
Dans GNS3 :
- Clique sur l’icône **PC / VM**
- Glisse **UbuntuDesktop26** dans ton lab
# # 5. Connecter Ubuntu au switch LAN

Dans GNS3 :
- UbuntuDesktop26 → switch port 3
- WindowsServer2022 → switch port 2
- pfSense em1 → switch port 1
# # 6. Vérifier que Ubuntu reçoit une IP du DHCP pfSense

Dans Ubuntu → Terminal :
```
ip a
```
On doit voir :
- IP : **192.168.1.101** (ou autre dans la plage DHCP)    
- Passerelle : **192.168.1.1**
- DNS : **192.168.1.1**

Si besoin :
```
sudo dhclient -r
sudo dhclient
```

# # 7. Tester la connectivité

### Depuis pfSense :
```
ping 192.168.1.101
```

### Depuis Ubuntu :
```
ping 192.168.1.1
ping 8.8.8.8
ping google.com
dig google.com
```

Résultats attendus :
- Réponse de pfSense → LAN OK
- Réponse de 8.8.8.8 → Internet OK
- Réponse de google.com → DNS OK
