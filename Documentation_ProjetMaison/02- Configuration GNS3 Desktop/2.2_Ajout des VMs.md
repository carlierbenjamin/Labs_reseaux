Une fois les VM créées dans VirtualBox :
### Étape A — Dans GNS3
Menu → **Edit → Preferences**

### Étape B — VirtualBox
- Active l’intégration VirtualBox
- Clique sur **VirtualBox VMs**
- Clique sur **New** pour les importer dans GNS3 -> local computer
- Au besoin allumer la VM - Tu vois apparaitre les VM Windows / Ubuntu
### Étape C — Ajouter dans ton projet
Dans GNS3 :
- Clique sur l’icône **PC / VM**
- Glisse **Windows** dans ton projet
- Glisse **Ubuntu** dans ton projet
